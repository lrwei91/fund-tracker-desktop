| 市场涨跌家数 | 东方财富 | — | 沪深京当前有效行情样本；上涨、下跌、平盘为空时不显示零值 |

## 可靠性规则

- 主窗口刷新由统一队列调度，普通请求最多三个并发；自选与持仓行情批次收齐后立即批量回填，不等待资金流、板块等剩余任务。部分行情批次失败时保留可用结果并标记降级。

- 东方财富统一单并发，最小启动间隔 1 秒并增加最多 300ms 抖动。
- 403 立即熔断；连续网络、429 或 5xx 失败后熔断 5 分钟，半开时只放行一次探测。
- 对必须有数据的接口同时校验 HTTP 状态和有效行数；空结果会触发备用源。
- 无数据使用 `null` / `available: false`，不以零值或红绿色 `--` 伪装。
- 机会雷达只深度分析前 8 名；少于三个核心组件可用时不生成综合分，并返回覆盖率与缺失来源。
- AI 研究与原生价格提醒的口径、数据发送范围及运行限制见 [功能说明](stock-research-and-alerts.md)。
- 软件版本更新使用独立原生 updater，来源固定为本项目 GitHub Releases，必须通过签名校验；见 [检测更新与自动安装](automatic-updates.md)。

## 原生持仓报告

`research_reports.rs` 负责配置、任务、去重、状态和历史；`trading_calendar.rs` 保存带来源的 2025–2026 年交易日历，未知年份不推断开市。自动任务按北京时间 09:00 / 15:30 调度，补跑截止分别为 09:25 / 16:30；不补跑往日记录。原生后台与手动研究共用模型信号量，手动请求优先。

股票快照必须对应盘前的上一交易日或盘后的当日收盘，技术资料也必须对应该日期。持仓市值只计入数量和有效报价完整的记录；盈亏还要求成本完整。ETF 计入可用统计但不套用公司财报研究。资料不够时不调用模型，部分资料可用时报告标明覆盖范围。

原生任务状态和去重记录在 `fund_tracker_report_center` 内原子保存，前端镜像不能写回；发送模型请求前先持久化状态，重启后中断的任务不自动重发。持仓成本、股数、权重可能发送给模型；备注不发送，不把密钥或带凭据请求写入报告。最近保留 60 份结构化报告，去重状态独立于历史截断。
