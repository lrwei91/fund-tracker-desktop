| 能力 | 主源 | 独立备用源 | 说明 |
|---|---|---|---|
| 实时行情、指数 | 腾讯 | — | 指数迷你图使用真实 242 点分时，不生成模拟曲线 |
| 市场涨跌家数 | 东方财富 | — | 沪深京当前有效行情样本；上涨、下跌、平盘为空时不显示零值 |

| AI 个股研究 | 用户配置的兼容 OpenAI API | — | 手动执行、结构化校验；分数为研究判断，非上涨概率 |

## 可靠性规则

- 主窗口刷新仍由统一队列调度，普通请求最多三并发；自选与持仓行情批次收齐后立即批量回填，不等待资金流、板块等剩余任务。部分行情批次失败时保留可用结果并标记降级。

- 东方财富统一单并发，最小启动间隔 1 秒并增加最多 300ms 抖动。
- 403 立即熔断；连续网络、429 或 5xx 失败后熔断 5 分钟，半开时只放行一次探测。
- 对必须有数据的接口同时校验 HTTP 状态和有效行数；空结果会触发备用源。
- 无数据使用 `null` / `available: false`，不以零值或红绿色 `--` 伪装。
- 机会雷达只深度分析前 8 名；少于三个核心组件可用时不生成综合分，并返回覆盖率与缺失来源。
- AI 研究与原生价格提醒的口径、数据发送范围及运行限制见 [功能说明](stock-research-and-alerts.md)。
- 软件版本更新使用独立原生 updater，来源固定为本项目 GitHub Releases，必须通过签名校验；见 [检测更新与自动安装](automatic-updates.md)。
