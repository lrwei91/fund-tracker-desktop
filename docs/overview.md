# 数据源与降级说明

## 当前路由

| 能力 | 主源 | 独立备用源 | 说明 |
|---|---|---|---|
| 实时行情、指数 | 腾讯 | — | 指数迷你图使用真实 242 点分时，不生成模拟曲线 |
| 市场涨跌家数 | 东方财富 | — | 沪深京当前有效行情样本；上涨、下跌、平盘为空时不显示零值 |
| 日 K、分时 | 腾讯 HTTP | tdxrs、东方财富 | tdxrs 为可选加速，不是安装依赖 |
| 个股资金流 | 东方财富 | 新浪财经 | 新浪备用源只展示可确认的主力净额 |
| 龙虎榜 | 东方财富 | 沪深交易所官方 | 官方源没有净买额时返回空值，不参与资金评分 |
| 财经快讯 | 金十、财联社、东方财富 | 三者互相降级 | 页面显示实际使用来源 |
| 北向数据 | 同花顺沪股通分钟序列 | HKEX 官方日统计 | HKEX 展示成交额，不描述为净流入 |
| 公告 | 深交所官方 / 东方财富 | 东方财富 | PDF 仅允许通过受限外部链接打开 |
| 限售解禁 | 东方财富 | — | 使用 `FREE_SHARES_TYPE`、`FREE_SHARES`、`ABLE_FREE_SHARES` 新字段 |

## 可靠性规则

- 东方财富统一单并发，最小启动间隔 1 秒并增加最多 300ms 抖动。
- 403 立即熔断；连续网络、429 或 5xx 失败后熔断 5 分钟，半开时只放行一次探测。
- 对必须有数据的接口同时校验 HTTP 状态和有效行数；空结果会触发备用源。
- 无数据使用 `null` / `available: false`，不以零值或红绿色 `--` 伪装。
- 机会雷达只深度分析前 8 名；少于三个核心组件可用时不生成综合分，并返回覆盖率与缺失来源。
