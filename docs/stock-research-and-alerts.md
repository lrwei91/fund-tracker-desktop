# AI 研究、个股详情与价格提醒

工作台融合 PanWatch 的“组合摘要、候选筛选、结构化研究、提醒规则、报告历史”思路，沿用本项目 Tauri 2、Rust 和原生 JavaScript。参考上游版本：[`59a6aad`](https://github.com/TNT-Likely/PanWatch/tree/59a6aad521354c8297df3e9536e2281e17444ee5)。没有引入 Python 服务、React 或 TradingAgents 运行依赖。

## 使用入口

- 设置 → AI 服务：填写兼容 OpenAI Chat Completions 的公网 HTTPS 基础地址，或本机 HTTP/HTTPS 地址（例如 `http://127.0.0.1:8788/v1`）、模型名称和 API 密钥。请求路径自动追加 `/chat/completions`。密钥保存在 macOS 钥匙串 / Windows Credential Manager；前端、本地配置和研究历史不保存密钥。更换基础地址时需要单独保存对应密钥；密钥输入框留空表示保留当前地址的密钥。
- 研究 → 候选初筛：选择机会初筛或全部自选，手动研究前 3、5、10 只。单次只执行一个模型请求，逐只展示进度、失败与结果，并按 AI 评估分排序。“停止后续”等待正在执行的请求结束后停止。
- 点击股票 → 研究：查看行情日期、估值、量化因子、覆盖率、已披露财务指标；手动生成支持理由、反对理由、观察条件和失效条件，可打开历史研究。
- 提醒中心，或个股 → 价格提醒：设置价格、涨跌幅、成交额（元）、量比的比较或穿越条件，组合 AND / OR，并设置冷却时间、每日次数、到期与单次触发。

持仓、快讯及原有持仓相对涨跌提醒继续保留。独立“盘中筛选”页面入口已移除，旧数据路由保留兼容；研究页采用统一快照，替代旧的分散规则结论展示。

## 数据与评分

`/stock-research` 聚合腾讯行情、现有日 K 技术指标、资金流、个股新闻、公告/解禁及东方财富财务指标。财务只接受已披露记录，缺失数字使用空值。研究快照保留各来源响应及可用状态；成功但空的数据不计入覆盖率。停牌、休市时行情日期仍显示原始日期。

三类分数含义独立：机会初筛分用于候选排序；量化研究分使用技术趋势、资金方向、新闻关键词、盈利变化四个可解释维度等权计算，名称含 ST / 退时扣 30 分；AI 评估分为模型基于相同快照的主观研究判断。三者都不代表上涨概率。至少要有有效行情和三个可用的评分维度才进入 AI 研究，资料不足时不生成量化分，模型可返回“待复核”且不评分。

手动个股/批量研究只发送个股公开数据，不发送持仓成本、数量或备注。盘前盘后组合报告的数据范围见下节。模型返回结构必须经过 JSON、评级、分数范围、来源可用性和文本长度校验。校验失败不采用结论。来源可用性校验不能证明模型的每句解释准确，用户仍需核对原始资料。

相同基础地址、模型和数据快照的研究缓存 15 分钟；最多保存 60 条研究，单只显示最近 10 条。历史结果显示生成时间、研究行情时点及缺项，不能作为当前评分。打开详情、定时刷新和读取历史不会自动调用模型。

## 盘前盘后持仓报告

- 研究页提供两个独立开关，默认关闭。交易日北京时间 09:00 生成盘前报告，15:30 生成盘后报告；手动按钮明确消耗模型额度。
- 使用 [上交所2025年](https://www.sse.com.cn/disclosure/announcement/general/c/c_20241223_10767108.shtml)、[2026年](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml) 年度休市通知，当前年份不在已知日历内时暂停自动执行。调休周末仍休市。
- 自动任务仅在应用运行期间执行，隐藏主窗口仍有效；退出和休眠不执行。启动/唤醒后，盘前 09:25 前、盘后 16:30 前允许补跑；过时仅记为错过，不追补往日。
- 默认深研有效市值最高的 5 只股票，同值按代码排序。组合统计覆盖所有可计算持仓；未选标的、ETF、数量或资料缺项逐项说明。无有效研究快照时不请求模型。
- 报告允许发送成本、股数、权重及公开数据，不发送备注。市值、盈亏和覆盖率由本机计算；模型只生成风险、个股研究、观察条件与限制，不能返回替代统计字段。来源和结构校验不能证明叙述中每个数字正确，仍需核对依据。
- 每份报告一次模型请求，自动任务每日最多两次。发送前记录状态，失败不自动重试；手动重试另行使用额度。手动研究优先，排队超出补跑窗口的自动任务不再调用模型。
- 取消只适用于尚未发送模型请求的任务。关闭自动开关会取消该类待执行任务；已经发送的模型请求不能撤回。
- 最近 60 份记录包含结构化报告、关键资料和时点；应用中断后不会自动重新发送。完整报告保存成功后才弹出中性桌面提示，点击跳转到研究页，不播放涨跌音效。

## 提醒运行边界

Rust 原生任务每 30 秒监控，在沪深交易时段检查，复用前端最近 30 秒报价；必要时经现有 gateway 补齐。报价必须具有有效日期时间且距当前不超过 120 秒，条件指标缺失时不触发、不重置防重复状态。穿越条件需要前一次有效观测；默认持续满足只触发一次，离开条件后才能重新触发。

规则、触发次数、防重复状态与最近 100 条记录通过 `ConfigStore.update_data` 同一原子事务持久化，保存失败不发送通知。主窗口隐藏不影响任务；退出应用、电脑休眠或离线无法持续监控。交易日未接入完整节假日日历，休市旧报价由时效校验拦截。一个提醒窗口同轮触发时显示最新提醒，全部触发记录保留在历史中。

## 代码契约

前端：`stock-research.js`、`price-alerts.js`；个股入口：`watchlist/stock-detail.js`。

报告接口 `/research-reports` 支持 `list/get/settings/run/retry/cancel/read`，仅主窗口可调用；`research-report-state` / `research-report-open` 向主窗口发送状态与打开事件，原生通知使用 `research-report-notice`。前端不另建报告轮询定时器。

后端：`api/handlers/research.rs` 提供 `/stock-fundamentals`、`/stock-research`；`research_ai.rs` 提供主窗口专用 `/stock-ai-research`（含历史读取）；`price_alerts.rs` 提供主窗口专用 `/price-alerts` 和原生监控。`ai_settings_status` / `ai_settings_save` 只允许主窗口配置凭据。

新增 v2 配置字段：`fund_tracker_ai_settings`（地址与模型）、`fund_tracker_price_alerts`、`fund_tracker_research_history`、`fund_tracker_report_center`。报告状态仅由原生接口写入，前端配置镜像无权覆盖。旧配置字段继续兼容，自选导入导出的范围保持为自选、持仓和自选指数；新提醒与研究通过应用配置持久化。

模型请求经 gateway 的请求合并、并发、超时和响应体限制。允许用户配置的精确公网 HTTPS 域名，或 `localhost`、IPv4/IPv6 回环地址的 HTTP/HTTPS 服务及自定义端口；不允许其他 HTTP/IP 地址、地址内凭据、查询参数或片段，带密钥的请求不跟随重定向，不向 renderer 开放任意联网、文件或进程权限。

## 验证入口

`npm run lint`、`npm test`、`npm run smoke`；Rust 使用 `cargo fmt`、`cargo clippy --all-targets -- -D warnings` 和完整 `cargo test`。

新增真实公开数据 smoke：`RUN_LIVE_DATA=1 cargo test --manifest-path src-tauri/Cargo.toml research_live_smoke -- --nocapture`。该检查不调用模型。真实模型研究需要用户配置自己的服务与密钥；浏览器样本验证不能证明模型 API、系统凭据权限或原生提醒已在真实交易时段运行。
