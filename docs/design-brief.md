# 恭喜发财桌面端设计简报

## 产品主线

个人盯盘工作台：查看持仓 → 研究标的 → 设置提醒 → 阅读报告。借鉴 PanWatch 对组合摘要、研究流程与报告历史的组织方式，保留本项目的轻量桌面形态和黑白黄视觉，不引入它的 React/Python 服务。

## 信息架构

- 盯盘：本机市值、浮动盈亏、数据覆盖、提醒摘要；持仓与自选分组表格；宽屏侧边详情。
- 市场：指数、自选指数、涨跌家数、资金、板块；轮动、热榜、打板归入二级市场观察。
- 研究：候选初筛、个股/批量研究、盘前盘后报告和历史。
- 提醒：条件规则、启停、到期及触发记录。
- 资讯：来源切换与快讯时间线。设置留在导航底部。

## 视觉与交互

- 白纸、近黑墨色、荧光黄；深色采用中性碳黑。涨跌、告警状态与选中强调各有独立语义。
- 摘要使用对齐数字与细线分组；数据区域优先表格和连续列表，减少重复卡片、阴影与装饰。
- 共享组件在 `styles.css`，新版导航与工作台布局集中在 `workbench.css`。数字采用等宽字体。
- 文字与容器边界保持留白：工作台标题栏、正文左右统一 16px，窄窗为 12px；列表自身的背景色块仍保留内部间距。详情、设置和浮窗分别保留内部留白，长文本换行或明确截断，不挤占关闭按钮与窗口控件。
- 详情按行情、研究、资金、提醒组织，成本/股数/备注采用明确编辑入口。
- loading 保留布局；empty 解释原因；error 可恢复；缓存、降级、资料时点与缺项明确可见。
- 研究分数不表述为上涨概率；模型叙述与本机计算的组合统计分开呈现。
- 原生报告提示使用中性通知，可点击查看报告，不播放涨跌音效。

## 响应式

- 默认主窗口 1280×860，按屏幕工作区收缩；原生最小宽度 540px。
- 1100px 起：列表与详情并排；1000px 起：完整侧栏；650px 以下：底部导航。
- 小窗采用全宽详情弹层；关闭恢复列表位置与焦点。宽窄跨断点时关闭详情以恢复正确语义。
- 390px 仅作为 WebView 内容回退验收，不改变原生窗口下限。

## 验收

覆盖 1440px、1280px、540px、390px，主窗口五页面、设置、详情、提醒规则、报告历史、持仓浮窗与原生告警；检查浅色与深色主题、键盘焦点、Escape、长内容、200% 缩放、reduced-motion、横向溢出和失败状态。构建、合成数据浏览器与原生运行证据分别记录。
