# 恭喜发财桌面端设计简报

## 设计判断

这是一个面向个人投资者的高密度桌面行情工具，以白纸、黑墨和荧光黄建立快速扫描、数据新鲜度确认和风险识别的编辑式产品界面。与现行美术基线的偏离包括：不使用展示型 Hero 和 820px 阅读轴，降低动效强度，提高信息密度，并为长期桌面使用扩展深色与跟随系统模式。

## 视觉旋钮

- `DESIGN_VARIANCE 5`：在严格数据对齐中保留轻度不对称层级，避免装饰性错位。
- `MOTION_INTENSITY 3`：只保留 hover、active、弹层和状态切换反馈，不引入滚动特效或持续动画。
- `VISUAL_DENSITY 8`：数字使用等宽字体，数据区以细线和留白分组，不堆叠同质卡片。

## 当前审计

- 现有主窗口使用冷蓝深色、琥珀强调、大量同质卡片和阴影，属于已退出的旧视觉体系。
- 主窗口、持仓浮窗、桌面告警分别维护色板，主题和状态表达存在分叉。
- 行情、自选、信号、快讯、设置、导入导出和个股详情的信息结构有效，应继续保留。
- 刷新协调器、真实数据与缓存/降级语义、Tauri IPC、持久配置和窗口行为不得因视觉重构改变。

## 保留与淘汰

保留：原生 HTML/CSS/JavaScript、Tauri、现有 DOM ID、主导航、红涨绿跌、响应式布局模式、用户配置和所有数据路径。

淘汰：冷蓝琥珀主视觉、常态渐变、常态阴影、重复卡片表面、只有“加载中”文字的空面板，以及跨窗口不一致的颜色值。

## 主题与状态

- 默认模式为 `light`，提供 `dark` 与 `system`；用户选择写入现有 `fund_tracker_settings`。
- 浅色使用白纸、近黑文字、32px 细网格和单一荧光黄强调。
- 深色使用中性碳黑与灰阶，不回退旧冷蓝色板；荧光黄职责不变。
- success、warning、error、info 与行情涨跌色独立，状态同时使用文字和结构表达。
- loading 保留最终布局，刷新不清空旧内容；empty 解释当前结果；error 提供可恢复操作。

## 响应式与验收

- 原生最小窗口保持 540px；592px 使用单列与底部导航，760px 开始双列，1280px 使用侧栏与三列工作台。
- 320px 与 390px 只验证 WebView 内容回退，不改变原生窗口下限。
- 验收覆盖主窗口三个页面、设置、自选数据、个股详情、持仓浮窗和告警弹窗，以及浅色、深色、跟随系统、键盘、减弱动效、200% 缩放和失败状态。
