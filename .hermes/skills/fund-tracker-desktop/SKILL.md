# Fund Tracker Desktop

用于本仓库 Tauri 桌面端维护的导航入口。按用户要求选择分析、修改或发布范围；读取本技能不代表要执行完整审查或发布。

## 按需定位

- 开始工作时读取仓库根 [AGENTS.md](../../../AGENTS.md)：项目边界、验证选择和授权规则以它为准，本技能不另设门禁。
- 了解开发、构建与数据来源时读取 [README.md](../../../README.md) 和 [数据源与降级说明](../../../docs/overview.md)。
- 定位行情、基金、信号、持仓和窗口入口时查阅 [功能与接口地图](../../../docs/module-map.md)，再查看本次涉及的模块。
- 修改视觉时读取 [设计说明](../../../docs/design-brief.md)。

## 执行范围

只给方案或整理文档时，不启动应用测试、构建或真实行情请求。代码修改按 AGENTS.md 的影响范围选择验证，复用同一代码与环境已有的通过结果。发布仅在明确授权后执行项目发布流程。

这些链接相对本技能目录解析；在其他位置使用时先定位实际仓库，不复制规则或从旧缓存重建规则。
