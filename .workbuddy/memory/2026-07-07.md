## UI Review + 清理（底栏没显示排查）

### 根因："底栏没显示" 是运行期问题，非 CSS 写法
- 源码 CSS 实际已正确：`.desktop-sidebar { grid-row: 2 }`、`.app-main-pane { grid-row: 1 }`、`.app-shell { overflow: hidden }`、`.desktop-sidebar { z-index: 220 }` 都已就位（这些似乎是用户在上一轮后自行补的）。
- 用户看不到底栏，是因为运行的是 **打包后的 dist/ 应用（app.asar 内是旧 CSS）** 或 **Electron 缓存了 CSS**。
- 已在 main.js `staticResponse` 加 `Cache-Control: no-cache`，避免开发期 CSS/JS 改动被缓存。
- 用户需 `npm start`（直接读源码）或 `npm run build:mac` 重新打包才能看到改动。

### Review 中发现并清理的遗留样式
1. `≤900px` 媒体查询里 `.desktop-sidebar-footer { width: 188px }` —— 旧左侧栏宽度(188px)的残留，底栏下 footer 不该被固定 188px 宽，已移除 `width`。
2. `.electron-app .desktop-brand-mark / .desktop-brand-name / .desktop-brand-subtitle` —— 品牌区在底栏模式 `display:none`，这三个子样式已死，已删除。
3. `@media (min-width: 1180px)` 整块（仅重复声明 dashboard 单列，base 已是单列）—— 冗余，已删除。

### Review 中确认"非冗余、保留"的项
- `@media (max-width: 1179px)` 里的 `#tab-signals.active` / `#tab-news.active` 单列规则：base 是 `repeat(2, minmax(360px,1fr))` 两列，窄屏需塌成单列，保留。
- `≤1179px` 里 `#tab-dashboard.active` 单列那行虽冗余但无害，未动。
- `@media (min-width: 768px)` 的 `#main-content/.tab-bar/.footer` max-width:760px —— 是 web 响应式样式，electron 窗口<760px 不受影响，无害。
