### 修复内容

1. **stock-minute.js**: 安装了 tdxrs (pip3 install tdxrs)，原候选链中的 `python3 -m tdxrs` 路径可用。新增腾讯分时 API (web.ifzq.gtimg.cn) 作为第二 fallback，在 tdxrs 和东财之间。

2. **stock-kline.js**: 新增 tdxrs bars 作为首要数据源，搭配腾讯复权日K作为 fallback。解决 push2his 不可用的问题。

3. **fund-flow-120d.js**: 将单端点改为多端点重试(push2his → push2)，单个股票失败不阻塞整体请求。

4. **news.js**: 新增东财快讯(np-weblist.eastmoney.com)作为金十502时的 fallback 数据源。

5. **market-data.js**: 主力资金和北向资金函数添加异常处理，push2/hexin 不可用时优雅降级返回空数据而非直接报 502。
