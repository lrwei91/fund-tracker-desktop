## 1. 术语与口径统一表

| 术语 | 统一口径（全文档一致） |
| --- | --- |
| **Tauri 2 + Rust** | 目标架构唯一权威表述（X1 裁决）。Rust 核心进程 + 系统 WebView 渲染；gateway / 配置 / 窗口管理由 Rust 提供。 |
| **Electron / Node.js** | 仅出现在 `AGENTS.md` 等过时资料中，视为**遗留描述**，不作为任何设计依据。 |
| **Rust 进程内 gateway** | 统一数据入口：合并在途 + TTL 缓存 + 熔断（403/连续失败 5 分钟熔断、半开仅一次探测）+ 多源 handler 降级元数据。对应 X2 裁决（落在 Rust 侧，非前端 JS `app/api/_gateway.js`）。 |
| **IPC / PCS** | Tauri commands/events；**仅开放事件能力**，不开放任意 fs / shell / process。对应 X3 裁决。 |
| **config.json v2** | 用户配置原子写入（临时写 + rename）+ 旧字段兼容；`localStorage` 仅临时缓存。 |
| **诚实表达** | 空值以 `null / available:false` 表达，不伪装为零值/红绿/净流入/确定结论；机会雷达核心组件 < 3 个可用时不生成综合分。 |
| **MVP / 完整版** | MVP = F1–F12 + N1/N2；F13 导入导出 / F14 自动更新 / F15 macOS 公证延后至完整版。 |
| **包体门禁** | 分发 ZIP ≤ 20MB；包内不含 Chromium / Node / Python / TDX；Windows 依赖系统 WebView2，macOS 用系统 WKWebView 且当前未公证。 |
