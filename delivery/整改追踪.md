## 后续版本与裁决

- **F13**：现有自选导入/导出仅作为已有基础，完整版再完成通用文件交互与正式验收。
- **F14/F15、U-03**：自动更新、签名和macOS公证归完整版。
- **U-01/U-04**：第三方实时可用性、再分发和快讯版权继续交法务/数据源负责人裁决。

## 验收边界

默认门禁为 `npm test`、`npm run check`、`npm run lint`、`npm run smoke` 和 Rust tests。双平台raw build验证N2。`RUN_LIVE_DATA=1 npm run smoke:data` 受网络、交易时段和上游风控影响，单独记录，不替代静态、单元或桌面运行验收。
